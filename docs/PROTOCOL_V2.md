# V2 小规模对照实验方案

在运行本轮实验前确定，不根据结果选择种子或追加调参；不声称正式预注册。

- 问题：同等训练交互预算下，稠密奖励DQN是否更会吃鱼？
- 对照：random、dqn_sparse、dqn_full。
- 任务：最多500步，死亡或到时结束；剩余时间作为第28维观测。
- DQN：每个种子15,000次环境交互，CPU单线程；训练种子0、1、2。
- 网络：Dueling；目标：Double DQN；探索：epsilon-greedy。
- 每个运行50个评估回合；DQN使用贪心策略，随机基线始终均匀选动作。
- 稀疏与稠密DQN共用超参数，使用不同训练奖励。随机基线不训练、不人为消耗训练预算。
- 主要指标：每局吃鱼数；辅助：死亡率、至少吃一条鱼的比例、统一任务回报。
- 统一回报为未折扣的 `5*fish - 5*death`；训练优化使用gamma=0.93的折扣回报，两者不同，不能宣称目标完全一致。
- 每个种子先对50局求均值，再汇总3个种子的均值和样本标准差。不是150个独立训练重复。
- 各方法使用匹配的评估环境种子。不同训练种子的评估集合由SeedSequence派生，避免相邻区间重叠。
- 同样种子不意味着动作不同后的鱼生成轨迹相同。只保证初始随机流匹配。
- 回合可能在训练预算用尽时尚未结束：记录budget_cutoff，但不把这一情况当成环境终止来禁止bootstrap。

## 保存与解释

保存每次运行的完整参数、逐回合训练记录、逐回合评估结果、运行汇总和模型。
顶层配置保存源码SHA-256、Git提交、软件版本。模型仅供评估，不声称支持精确恢复训练。
不选最佳种子作展示；新演示固定使用dqn_full/seed=0以及第一个评估环境种子。
旧21维演示及27维pilot不与V2数据混合。

这是一个小预算教学实验，不足以得出收敛性、显著性或普遍优越性结论。
