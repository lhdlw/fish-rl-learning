# 来源与版本说明

本仓库由本地“大鱼吃小鱼”学习原型和后续 `decision_intelligence_study` 整理。

| 内容 | 来源与用途 |
|---|---|
| fishrl、实验脚本 | 改进版学习项目；本次保留算法、补检查与文档 |
| prototype | 旧原型的环境、智能体、训练和演示脚本 |
| prototype/models | 旧实验中现存的一个模型，仅供演示；历史命名不保证最优 |
| media/ai_play.gif | 旧实验演示；未证明与仓库内模型为同一版本 |
| data/pilot/runs.csv、config.json | 改进版历史试运行记录，原样保留 |

代码与文档使用过AI辅助编写、解释及整理。作者本人独立完成与工具生成部分尚未逐段标注，
因此本仓库不声称全部独立实现。
